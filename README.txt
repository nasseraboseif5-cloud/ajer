صدقة جارية — نسخة تأسيسية للواجهة
==================================

محتويات المشروع:
- index.html: الصفحة الرئيسية.
- style.css: التصميم والألوان والاستجابة للموبايل.
- app.js: التفاعل والسبحة وتحميل نص السورة عبر API عند توفر الإنترنت.
- manifest.webmanifest و icon.svg و sw.js: إعدادات PWA والتخزين المؤقت.

التشغيل:
1) فك ضغط الملف.
2) ارفع محتويات المجلد إلى مستودع GitHub.
3) من Settings ثم Pages اختر النشر من الفرع main والمجلد root.
4) افتح رابط GitHub Pages. تثبيت PWA يتطلب HTTPS.

ملاحظات مهمة عن الدقة والاكتمال:
هذه نسخة أولية قابلة للتطوير وليست تطبيقًا دينيًا مكتملًا.
- نص السور يُحمّل عبر alquran.cloud عند الاتصال بالإنترنت؛ راجع المصدر ومطابقة النص قبل الاعتماد النهائي.
- لا يوجد حتى الآن مصحف مطابق لصفحات المدينة الـ604، ولا فهرس صفحات/أجزاء/أحزاب.
- لا يوجد تفسير مدمج.
- مشغل القراء والتسجيلات لم يُفعّل؛ لم نضع روابط صوتية غير متحقق منها.
- الأحاديث والأدعية والأذكار لم تُملأ بمحتوى تجريبي حتى لا ننسب نصوصًا دينية بلا توثيق.
- اتجاه القبلة يحتاج تنفيذًا واختبارًا على أجهزة مختلفة.
- التخزين دون إنترنت حاليًا يقتصر على ملفات الواجهة الأساسية.

لإضافة المحتوى الديني لاحقًا يجب استخدام مصادر موثوقة، ومراجعة النصوص والمراجع وحقوق الاستخدام قبل النشر.
